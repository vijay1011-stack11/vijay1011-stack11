### This is me :

I'm a final-year CS student (Class of 2027) at **SRM IST, Chennai**, working on **Edge AI**: compressing models so they can still make reliable decisions with limited compute, power and network access. Think rural clinics and disaster zones, where a dependable cloud connection is hard to find.

My latest result is one I can measure but can't explain yet: on an x86 CPU, my **INT8** skin-lesion model ran *slower* than **float32** (10.7 ms vs 6.9 ms). That's the kind of question I want to spend the next few years answering.
